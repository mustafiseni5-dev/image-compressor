Change pixel dimensions while preserving proportions. This page explains when to use it, how to interpret its output, and what to check before relying on the result.

Resize an image when a website, profile, form, or document requires specific pixel dimensions. Select the source image, enter the target width and height, and keep the aspect ratio locked when you want to avoid stretching faces, objects, or logos.

How to use this tool

  1. Open the tool and enter the value or choose the file it asks for.
  2. Check that the input and selected options match your intended task.
  3. Run the operation and review the result before copying or downloading it.
  4. Keep an original copy when the operation changes or transforms your input.

What to know before using it

Pixel dimensions describe the image width and height, not its file size. Resizing down usually reduces the number of pixels; resizing up cannot restore detail that was not present in the original.

Practical tip

Keep the original file until you have checked the resized image and confirmed it meets the destination platform’s requirements.
