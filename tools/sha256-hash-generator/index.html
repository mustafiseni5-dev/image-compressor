What to know before using it

A hash is not encryption and cannot be decoded to recover the original input. A plain SHA-256 hash is not appropriate by itself for password storage; password storage needs a purpose-built, salted, slow password-hashing algorithm.

Practical tip

A single whitespace or character difference changes the digest. Check the exact input encoding when comparing hashes.
