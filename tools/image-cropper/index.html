Image Cropper

Keep only the part of an image you need. This page explains when to use it, how to interpret its output, and what to check before relying on the result.

Cropping removes unwanted outer areas from an image. Choose a file, enter the crop rectangle, and preview the selected area before downloading. The crop coordinates and dimensions are measured in pixels from the top-left corner of the source image.

Open Image Cropper →

How to use this tool

  1. Open the tool and enter the value or choose the file it asks for.
  2. Check that the input and selected options match your intended task.
  3. Run the operation and review the result before copying or downloading it.
  4. Keep an original copy when the operation changes or transforms your input.

What to know before using it

The crop rectangle must stay inside the source image. If the crop looks blank or unexpectedly small, check the X and Y offsets and ensure width and height are positive.

Practical tip

Save a copy of the original first, especially if you may later need the parts outside the crop.
