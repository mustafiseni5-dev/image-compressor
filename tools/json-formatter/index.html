What to know before using it

JSON requires double-quoted strings and property names, valid commas, and no trailing commas. Comments and JavaScript expressions are not valid standard JSON.

Practical tip

Avoid pasting secrets, access tokens, or private production data into online tools. Even if parsing happens locally, use a safe workflow for sensitive information.
