Encode or decode text using Base64. This page explains when to use it, how to interpret its output, and what to check before relying on the result.

What to know before using it

Base64 is an encoding, not encryption. Anyone with the encoded value can usually decode it, so it must not be used to protect passwords, private keys, or confidential data.
