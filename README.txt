# Utilora 2.0

Files:
- index.html
- style.css
- script.js
- ads.txt
- assets/utilora-logo.png

Deployment:
1. Replace the current `index.html`, `style.css`, and `script.js` in your GitHub repo.
2. Put `ads.txt` in the repository root.
3. Put `utilora-logo.png` inside `assets/`.
4. Commit and push. Vercel should deploy automatically.
5. Open https://utilora.fun and test the tools.

The AdSense publisher script is kept in `index.html`.
